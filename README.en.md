## Overview

Lyra Music is an advanced Android music app built with **Jetpack Compose** and **Material 3**. It offers:

- **Spotify Playlist Import**: Match and import public Spotify playlists directly into Lyra using YouTube Music matching.
- **Synced Lyrics**: Time-synchronized lyrics from LRCLIB, BetterLyrics, and KuGou.
- **Spotify Canvas**: Video backgrounds during music playback.
- **Shazam Integration**: Built-in song identification via ShazamKit.
- **Discord & Last.fm**: Kizzy Discord Rich Presence and Last.fm scrobbling support.
- **Offline Mode**: Audio caching and playlist downloading.
