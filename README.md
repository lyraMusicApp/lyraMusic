## What's New

<img src="https://readme-typing-svg.herokuapp.com?font=Kaushan&size=24&duration=2600&pause=700&color=22C55E&width=650&lines=Paste+a+Spotify+playlist+link;Import+tracks+into+Lyra+Music;Create+or+choose+your+playlist" alt="Spotify import animated typing">

Lyra Music now includes Spotify playlist import inside **Settings > Backup & Restore**. Paste a public Spotify playlist link, choose or create a Lyra playlist, and the app matches tracks through YouTube Music so the playlist can live inside Lyra.

| Music | Library | Experience |

## Build From Source

Requirements:

- Android Studio
- Android SDK 36
- JDK 21

Build the signed release APK:

```powershell
.\gradlew.bat :app:assembleRelease
```

Generated APK:

```text
app/build/outputs/apk/release/app-release.apk
```
