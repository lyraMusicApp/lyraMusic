## ✨ Key Features

<table width="100%">
  <tr>
    <td width="50%" valign="top">
      <h3>🎨 Dynamic Material You Interface</h3>
      <p>Seamlessly adapts to your device's accent colors and system theme with fluid Jetpack Compose micro-animations and intuitive gestures.</p>
    </td>

      <h3>💚 Spotify Playlist Importer</h3>
      <p>Paste any public Spotify playlist URL to instantly match and import tracks directly into your Lyra library via YouTube Music matching engine.</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">

    <td width="50%" valign="top">

  </tr>
  <tr>
    <td width="50%" valign="top">

## 🛠️ Tech Stack & Libraries

Lyra Music is built following modern Android development best practices and architecture patterns:

| Layer | Technologies & Tools |
| :--- | :--- |
| **UI Framework** | [Jetpack Compose](https://developer.android.com/jetpack/compose), Material 3 Expressive Design |
| **Language** | [Kotlin 1.9+](https://kotlinlang.org/) with Coroutines & Flow |
| **Audio Engine** | AndroidX Media3 / ExoPlayer |
| **Backend & APIs** | YouTube Music / InnerTube, LRCLIB API, KuGou Engine, BetterLyrics |
| **Integrations** | ShazamKit (Song ID), Kizzy (Discord RPC), Last.fm API |
| **Build System** | Gradle Kotlin DSL (`build.gradle.kts`) |

## 💻 Building from Source

To compile and build Lyra Music locally, ensure you have **Android Studio Hedgehog / Iguana or newer** and JDK 17 configured.

### 1. Clone the repository
```bash
git clone https://github.com/shnwazdeveloper/lyraMusic.git
cd lyraMusic
```

### 2. Build the APK

- **Windows (PowerShell / CMD):**
  ```powershell
  .\gradlew.bat :app:assembleRelease
  ```

- **Linux / macOS:**
  ```bash
  chmod +x gradlew
  ./gradlew :app:assembleRelease
  ```

The generated APK file will be located at:
`app/build/outputs/apk/release/app-release.apk` (or signed as `lyraMusic.apk`).
