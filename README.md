### Download & Quick Start

<div align="center">

[![Download Signed APK](https://img.shields.io/badge/Download_APK-Release_v-8B5CF6?style=for-the-badge&logo=android&logoColor=white)](https://github.com/lyraMusicApp/lyraMusic/releases/latest)

</div>

1. Download the latest `app-release.apk` from [Releases](https://github.com/lyraMusicApp/lyraMusic/releases).
2. Install the APK on any device running **Android 8.0+**.
3. Open Lyra Music to stream, search, or download music immediately.

### Build From Source

```bash
# 1. Clone repository
git clone -b lyra https://github.com/lyraMusicApp/lyraMusic.git
cd lyraMusic

# 2. Build Release APK
./gradlew :app:assembleRelease    # Linux / macOS
.\gradlew.bat :app:assembleRelease # Windows
```
> Output APK: `app/build/outputs/apk/release/app-release.apk`
