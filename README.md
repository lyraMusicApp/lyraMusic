## What's New

<img src="https://readme-typing-svg.herokuapp.com?font=Kaushan&size=24&duration=2600&pause=700&color=22C55E&width=650&lines=Paste+a+Spotify+playlist+link;Import+tracks+into+Lyra+Music;Create+or+choose+your+playlist" alt="Spotify import animated typing">

Lyra Music now includes Spotify playlist import inside **Settings > Backup & Restore**. Paste a public Spotify playlist link, choose or create a Lyra playlist, and the app matches tracks through YouTube Music so the playlist can live inside Lyra.

## Features

| Music | Library | Experience |
| --- | --- | --- |
| Search songs, videos, albums, and playlists | Save songs, artists, albums, and playlists | Material You interface built with Jetpack Compose |
| Background playback with Android media controls | Import Spotify playlists from public links | Lyrics support when available |
| Download tracks for offline listening | Backup, restore, CSV, M3U, and playlist tools | Android Auto and modern notification controls |

| Step | Command |
| --- | --- |
| Install tools | Android Studio, Android SDK 36, JDK 21 |
| Open project | Clone the repo and open the root folder in Android Studio |
| Build release | `.\gradlew.bat :app:assembleRelease` |
| Find APK | `app/build/outputs/apk/release/app-release.apk` |

```powershell
.\gradlew.bat :app:assembleRelease
```
